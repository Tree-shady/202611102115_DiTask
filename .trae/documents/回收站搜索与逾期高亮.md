# 回收站、搜索与逾期高亮实施计划

## Context

PC 客户端已支持软删除，但用户无法查看或恢复已删除任务；任务列表也缺少内容检索和逾期提醒。本次依次实现回收站、标题/内容搜索、逾期行高亮，保持离线可用和现有多账号隔离行为。

已确认“彻底删除”采用**本机彻底删除**：云端保留不可见的软删除记录用于多端同步，不修改后端接口。

## 一、回收站

1. 在主窗口工具栏增加“回收站”入口，通过现有 ViewModel 事件模式打开独立模态窗口。
2. 新增 `ViewModels/RecycleBinViewModel.cs`：
   - 按 `UserId == 当前用户 && IsDeleted` 查询本地 SQLite，按 `UpdatedAt` 倒序。
   - “恢复”：设置 `IsDeleted=false`、`IsPendingSync=true`、`UpdatedAt=UtcNow`，允许离线操作，关闭窗口后刷新主列表。
   - “从本机彻底删除”：二次确认；先通过现有 `/api/v1/tasks/sync` 上传最新软删除标记，上传成功后才物理删除本地记录；离线或上传失败时保留记录并提示。
3. 新增 `Views/RecycleBinWindow.xaml` 和 `.xaml.cs`：复用主列表的只读 DataGrid、状态/优先级/UTC 时间转换器，提供恢复和本机彻底删除按钮。
4. 修改 `MainWindow.xaml.cs`：打开回收站时共享当前 `SettingsService`，窗口关闭后调用 `LoadTasksAsync()`。
5. 修改 `Services/SyncService.cs`：当本地记录不存在且云端 DTO 为 `IsDeleted=true` 时跳过，避免本机彻底清除后又被全量同步拉回；已有本地任务仍正常接收云端删除/恢复状态。

## 二、搜索

1. 修改 `MainViewModel.cs`：保留当前本地查询，在 `Tasks` 集合上创建 `ICollectionView`。
2. 新增 `SearchText`，变化时刷新视图；Filter 对标题和内容执行不区分大小写的包含匹配，空白关键字显示全部，空内容安全跳过。
3. 修改 `MainWindow.xaml`：工具栏下方增加搜索框，DataGrid 改绑筛选视图；搜索仅影响当前用户未删除任务，不访问远端服务。

## 三、逾期高亮

1. 修改 `Models/TaskItem.cs`：增加不落库的 `IsOverdue` 计算属性，条件为“未完成 + 有截止时间 + 截止时间早于当前 UTC 时间”；按现有约定处理 SQLite 读出的 `Unspecified` 时间。
2. 使用现有 `ObservableObject` 提供属性变更通知；主 ViewModel 用一分钟 `DispatcherTimer` 刷新当前列表的逾期状态，窗口关闭和退出登录时停止。
3. 修改 `MainWindow.xaml`：通过 `DataGrid.RowStyle` 和 `DataTrigger` 将逾期行显示为浅红背景、深红文字；已完成、未来截止和无截止时间任务不高亮。

## 涉及文件

- 修改：`ViewModels/MainViewModel.cs`、`Models/TaskItem.cs`、`Services/SyncService.cs`、`Views/MainWindow.xaml`、`Views/MainWindow.xaml.cs`
- 新增：`ViewModels/RecycleBinViewModel.cs`、`Views/RecycleBinWindow.xaml`、`Views/RecycleBinWindow.xaml.cs`
- 复用：`Converters/ValueConverters.cs`、`Services/ApiClient.cs`、`Data/AppDbContext.cs`

不修改服务端、接口契约、NuGet 依赖或数据库表结构。

## 验证

1. 执行完整 Rebuild，确保 net48 下 0 错误、0 警告并启动客户端。
2. 删除任务后确认仅当前账号回收站可见；离线恢复到主列表，联网后同步恢复状态。
3. 离线彻底删除应失败且保留记录；在线彻底删除后，重复同步、重启及重新登录均不得在本机复活。
4. 分别验证标题匹配、仅内容匹配、大小写、空关键字和空内容；其他账号及已删除任务不得出现在结果中。
5. 验证待办/进行中逾期任务高亮，已完成、未来截止、无截止时间任务不高亮，并验证跨过截止时间后自动刷新。
6. 回归新增、编辑、完成/重开、手动同步及 401 自动返回登录。
