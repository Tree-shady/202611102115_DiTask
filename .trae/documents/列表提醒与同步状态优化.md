# 列表、提醒与同步状态优化计划

## Context

本轮处理用户选择的“列表与提醒 + 同步状态”：让任务检索更精确、截止提醒更实用，并让离线编辑后的待同步数量和连接状态清晰可见。复用现有 MVVM、`TasksView`、分钟计时器和同步流程，不修改后端接口或数据库结构。

## 一、组合筛选与列表展示

1. 修改 `ViewModels/MainViewModel.cs`：
   - 增加 `StatusFilterIndex`（全部/待办/进行中/已完成）和 `PriorityFilterIndex`（全部/普通/重要/紧急）。
   - 与 `SearchText` 共用唯一的 `TasksView.Filter`，三个条件按 AND 组合；筛选仅影响显示，不影响待同步统计。
2. 修改 `Models/TaskItem.cs`：
   - 增加不落库的单行 `ContentSummary`，归一化换行和连续空白，截取约 80 个字符。
   - 增加 `IsDueToday`：未完成且 UTC 截止时间转换到本地后为今天；现有时间刷新同时通知逾期和今天到期状态。
3. 修改 `Views/MainWindow.xaml`：
   - 搜索栏增加状态、优先级 ComboBox，复用编辑窗口的 `SelectedIndex` 绑定方式。
   - 增加“详情摘要”列并适当加宽窗口。
   - 今天到期显示浅黄色，逾期仍显示浅红色且优先覆盖黄色，已完成任务不着色。

## 二、截止时间与提醒

1. 修改 `ViewModels/TaskEditViewModel.cs` 和 `Views/TaskEditWindow.xaml`：
   - DatePicker 旁增加 `HH:mm` 时间输入，新任务默认 18:00，已有任务按本地时间回显。
   - 保存时严格校验小时分钟，非法输入阻止保存且不部分修改实体。
   - 将本地日期和时间组合后转换为 UTC，仍写现有 `TaskItem.DueTime`，同步 DTO 不变。
2. 修改 `MainViewModel.cs`：
   - 使用运行期 `HashSet<string>` 记录已提醒任务。
   - 启动本地列表加载后检查一次，之后复现有一分钟计时器检查；离线也能提醒。
   - 对未完成且已到截止时间的任务合并为一个 `MessageBox`，最多列出前 5 项，其余显示数量。
   - 每个任务每次程序运行最多提醒一次，已完成任务不提醒，不引入 Toast 或新依赖。

## 三、同步状态

1. 在 `MainViewModel.cs` 增加：
   - `LastSyncTimeText`：由现有 `LastSyncTime` 转换为本地时间，无记录显示“从未同步”。
   - `PendingSyncCount`：按当前 `UserId` 直接统计 SQLite 中所有 `IsPendingSync` 记录，包含主列表不可见的软删除任务，不受筛选影响。
   - `ConnectionStateText`：初始“未检测”，成功后“在线”，连接失败/超时后“离线”，服务器返回非 401 HTTP 错误时保持“在线”但显示同步失败。
2. 在加载、新增、编辑、完成/重开、软删除、同步成功/失败及回收站关闭刷新列表时更新相应状态；只有完整同步成功才更新上次成功时间。
3. 修改 `Services/ApiClient.cs`：增加轻量 `NetworkApiException`，仅在 `HttpRequestException` 和超时时抛出；现有 401 和普通 HTTP 异常行为不变。
4. 底部状态栏保留 `StatusMessage`，增加“连接状态、待同步数量、上次成功同步时间”三个短字段。沿用当前退出登录清空同步游标的逻辑，不增加设置迁移。

## 涉及文件

- `ViewModels/MainViewModel.cs`、`ViewModels/TaskEditViewModel.cs`
- `Models/TaskItem.cs`
- `Services/ApiClient.cs`
- `Views/MainWindow.xaml`、`Views/TaskEditWindow.xaml`

复用现有 `SyncService.cs`、`SettingsService.cs`、`Converters/ValueConverters.cs`；不新增 NuGet 包，不修改服务端。

## 验证

1. 完整 Rebuild 并启动，确保 net48 下 0 错误、0 警告。
2. 验证搜索、状态、优先级按 AND 组合，编辑和同步后筛选仍有效。
3. 验证本地日期时间保存为正确 UTC，重新打开回显一致，非法时间被阻止。
4. 两项任务同时到期只弹一个合并框，下一分钟不重复；已完成、未来及无截止时间任务不提醒。
5. 验证摘要单行显示、今天到期黄色、逾期红色优先、已完成无色。
6. 新增、编辑、完成、软删除、回收站恢复后待同步数量准确；完整成功后更新时间，失败时不推进。
7. 正常服务显示在线；不可达地址或超时显示离线；HTTP 500 不误报离线；401 自动重新登录保持不回归。
